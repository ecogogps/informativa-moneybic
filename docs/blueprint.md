# **App Name**: Simple Canvas

## Core Features:

- Display 'Hola Mundo': Render the phrase 'Hola Mundo' prominently on a blank web page.

## Style Guidelines:

- Primary text color: Very dark, subtle blue-grey (#2E3236) to ensure high readability on a white background, evoking stability and digital clarity.
- Background color: Pure white (#FFFFFF), directly reflecting the request for a 'blank' page.
- Accent color: A clean and vibrant cyan (#33CCCC) for potential future interactive elements, offering a sharp digital contrast.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly legible appearance, suitable for displaying fundamental text clearly.
- The text 'Hola Mundo' will be centrally aligned, both horizontally and vertically, on the page for maximum emphasis and minimalist design.
